Версия для независимой проверки. Полный повтор из сырья и независимая проверка в Cloud не выполнены. Код использует Python 3.12; версии в requirements.txt совпадают с основным запуском. На Windows использовать `python -X utf8 -B`; на Linux также подходит эта команда. Явная writable временная папка обязательна, переменная TEMP не требуется.

1. Установить зависимости в собственную среду: `python -m pip install -r requirements.txt`.
2. Взять официальный лицензированный consumption.parquet по sources/SOURCES.md. Сырья/весов/полного индивидуального кэша в архиве нет.
3. Создать независимый кэш: `python -X utf8 -B code/v4_make_cache.py --config config/PROTOCOL.json --data /path/consumption.parquet --output /new/path/cache.csv --temp-dir /writable/tmp`. Это медленный полный пересчёт Prophet, он не выполнялся заново для основного ансамбля.
4. Запустить в НОВОЙ папке: `python -X utf8 -B code/v4_reproduce.py --config config/PROTOCOL.json --cache /new/path/cache.csv --sigma config/DETECTOR_SCALE.json --run-dir /new/path/run --temp-dir /writable/tmp`. `--prepare-only` создаёт freeze без расчёта. BURNED-папку не перезаписывать.
5. Искусственные проверки: `python -X utf8 -B code/v4_checks.py`; numerical packages должны быть установлены.

Для локальной точной арифметики исходный проверенный кэш доступен исполнителю по source_cache.relative_path в JSON. Regenerated cache получает собственный SHA/recipe; его байтовое совпадение не предполагается. Base-model settings и profile IDs при старом кэше менять нельзя. Для нового кэша рецепт должен совпадать с конфигом.

Настраиваемые параметры: ensemble.prior, l1_penalty, loss_scale_floor, feasibility_tolerance; detector.calibration_alarm_budget и threshold_grid; bootstrap repetitions/seed/quantiles. Изменение base_model применяется только в make_cache, с новым recipe. Разбиение, категории, даты, горизонты - зафиксированный дизайн эксперимента, не свободные ручки настройки. Смена параметров образует новый результат, не исправление основного ансамбля задним числом.

Все категории включают агрегат и имеют равный вес. Полная исходная панель 2024 уже изучалась; интервалы условны, не доказывают новый макрорежим. Сигнал появляется после наблюдения; вероятность шока и предупреждение до события не установлены. Historical_v2 - отдельные сохранённые benchmark/контекст, числа, не пересчитанные для основного ансамбля.

Формат собственного CSV прогнозов 2024: territory_id,category,prefix_n,horizon,target_index,actual,prediction,reference_scale,mase_scale,method. Индекс 0 - Jan2023; prefix_n число наблюдений. Официальный единый CSV-шаблон результата не найден. Для конкурса требуются описание/отчёт, код+конфиг+инструкции и PDF либо интерактивная презентация, доступная жюри ссылка.

Собственный код: © 2026 Артур Шафиев, все права защищены; сторонние лицензии действуют отдельно. Независимые служебные ревью хранятся отдельно от публичного состава. Прежние результаты первых сравнений и диагностики не переименовываются в победу.

## Применение на последнем снимке

`python -X utf8 -B code/v4_snapshot.py --config config/PROTOCOL.json --cache /path/original_verified_cache.csv --data /path/consumption.parquet --output-dir /new/path/projection --temp-dir /writable/tmp --workers 4`

Этот сохранённый запуск построил 36 288 прогнозов для 12 096 рядов из 2016 МО. Горизонты 1/3/6 месяцев относятся к январю, марту и июню 2025 года из снимка конца декабря 2024. Исходная команда требует байтово точный старый кэш. Для кэша с другой контрольной суммой ниже предоставлен отдельный адаптер с проверкой рецепта и происхождения. В сохранённом применении были ещё 3 задачи обучения весов и 12 096 обучений Prophet; они не входят в 19 задач обучения весов исторической оценки и не меняют её результаты. Применение к данным 2026 года не выполнено. Полный индивидуальный CSV не включён.

Байтовое тождество удалённого ZIP локальному intake не подтверждено.

## Проекция с новым кэшем

`python -X utf8 -B code/release_v4_snapshot_transport.py --config config/PROTOCOL.json --cache /new/path/cache.csv --data /path/consumption.parquet --output-dir /new/path/snapshot_transport --temp-dir /writable/tmp --prepare-only`

Transport проверяет raw SHA и рядом с независимым новым cache.csv ожидает cache.recipe.json от v4_make_cache.py. Рецепт моделей, профиля, дат, горизонтов, категорий и колонок должен совпасть. Создаются отдельный config с новым cache SHA и квитанция происхождения. `--prepare-only` не выполняет fit. Снять этот флаг означает отдельный реальный запуск projection в новой папке; поставленный transport пока проверен только в режиме подготовки/на искусственном recipe, полная проекция из нового кэша не выполнена. Он не меняет зафиксированный основной ансамбль и не добавляет h12. Прогноз на январь/март/июнь 2025 остаётся исторической проекцией из конца 2024, не прогнозом на 2026.

Служебные RESULT/старые протоколы сохраняют исходные исторические поля by/stop_go/handoff. Они фиксируют состояние научного запуска и не служат инструкциями пользователю или автоматическим разрешением отправки. Внешние условия проверяются отдельно.

Для графиков установите `python -m pip install -r requirements-plots.txt` (проверенная версия 3.11.2). Редактируемые графики PPTX используют прогнозные значения, округлённые до 6 знаков после запятой; исходные CSV сохраняют полную точность.

PDF содержит 12 страниц формата 16:9, построенных из окончательного PPTX. В PDF страницы растровые; текст, таблицы и графики редактируются в поставленном PPTX. Все 12 страниц проверены через чтение PDF и рендер. Открытие в настольных PowerPoint/Acrobat остаётся не проверенным.


В отчёте и презентации используются понятные названия методов. METHOD_ALIASES.json связывает их с техническими версиями и неизменными именами в результатах. Файлы кода и протоколы сохраняют исходные идентификаторы.

Основной формат просмотра презентации - presentation.pdf. Для редактирования предназначен presentation.pptx; при отсутствии Segoe UI возможна подмена шрифта и изменение вёрстки.
